# Backrooms Three.js Game

A self-contained browser game set in Level 0 of the Backrooms.

## Run

Open `index.html` in a modern browser. If your browser blocks ES modules from `file://`, run a local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Controls

- **WASD** — move
- **Mouse** — look around
- **Shift** — sprint
- **F** — toggle flashlight
- **Esc** — release the mouse

The game uses Three.js from jsDelivr and has no build step or external assets.
